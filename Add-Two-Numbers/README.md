# Program 1: Add Two Numbers

## Problem Statement
Write a Prolog program to add two numbers.

## Algorithm / Approach
1. Define a predicate `add_numbers`.
2. Take two integer values as input.
3. Add the two numbers.
4. Store the result in a third variable.
5. Display the result.

## Program

The program uses the `add_numbers(A, B, Sum)` predicate to calculate the sum.

## Sample Input

```text
10, 20
